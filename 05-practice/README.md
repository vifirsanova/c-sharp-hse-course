## Шпаргалка по методам строк

| Метод | Пример | Результат |
|---|---|---|
| `IndexOf` | `"a.b".IndexOf('.')` | `1` |
| `Substring` | `"abc".Substring(1)` | `"bc"` |
| `ToUpper` | `"abc".ToUpper()` | `"ABC"` |
| `Split` | `"a,b".Split(',')` | `["a", "b"]` |
| `Replace` | `"abc".Replace("a","x")` | `"xbc"` |

## Арифметика

| Операция | Пример | Результат |
|---|---|---|
| Целочисленное деление | `5 / 2` | `2` |
| Деление с плавающей | `5.0 / 2` | `2.5` |
| Остаток | `5 % 2` | `1` |
| Инкремент | `i++` | +1 |
| Декремент | `i--` | -1 |

## Строки

| Способ | Пример |
|---|---|
| Конкатенация | `"Name: " + name` |
| Интерполяция | `$"Name: {name}"` |

## Преобразование типов

| Вид | Пример |
|---|---|
| Неявное | `int a = 10; double b = a;` |
| Явное | `double c = 7.85; int d = (int)c;` |
