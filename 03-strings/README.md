### Основные операции
| Операция | Синтаксис | Пример | Результат |
| :--- | :--- | :--- | :--- |
| **Конкатенация** | `+` | `"Hello " + "World"` | `"Hello World"` |
| **Длина строки** | `.Length` | `"Hi".Length` | `2` |
| **Доступ к символу** | `[индекс]` | `"Hello"[0]` | `'H'` (тип `char`) |
| **Сравнение** | `==` / `!=` | `"Hi" == "Hi"` | `true` |

### Форматирование строк (Интерполяция)
Самый современный и удобный способ вставки переменных в строку.

**Синтаксис:** знак `$` перед открывающей кавычкой, переменные в фигурных скобках `{}`.

```csharp
string name = "Алексей";
int age = 20;

// Интерполяция
string info = $"Меня зовут {name}, мне {age} лет."; 
// Результат: "Меня зовут Алексей, мне 20 лет."
```

### Полезные методы класса `string`
Все методы возвращают **новую строку**, так как строки в C# неизменяемы (*immutable*).

| Метод | Что делает | Пример | Результат |
| :--- | :--- | :--- | :--- |
| `.ToUpper()` | Все буквы в верхний регистр | `"hi".ToUpper()` | `"HI"` |
| `.ToLower()` | Все буквы в нижний регистр | `"HI".ToLower()` | `"hi"` |
| `.Trim()` | Удаляет пробелы по краям | `"  hi  ".Trim()` | `"hi"` |
| `.Replace()` | Заменяет часть строки | `"hi".Replace("i", "o")` | `"ho"` |
| `.Contains()` | Проверяет наличие подстроки | `"Hello".Contains("el")` | `true` |
| `.StartsWith()` | Проверяет начало строки | `"Hello".StartsWith("H")` | `true` |
| `.EndsWith()` | Проверяет конец строки | `"Hello".EndsWith("o")` | `true` |

### Важные примечания для новичков

**1. Одинарные vs Двойные кавычки**
- `"Строка"` (двойные кавычки) $\rightarrow$ тип `string` (текст).
- `'С'` (одинарные кавычки) $\rightarrow$ тип `char` (один символ).

**2. Индексация**
Отсчёт символов в строке всегда начинается с **0**.
`"C#"[0]` $\rightarrow$ `'C'`
`"C#"[1]` $\rightarrow$ `'#'`

**3. Спецсимволы (Escape-последовательности)**
Если нужно вставить в строку спецсимвол, используйте `\`:
- `\n` — новая строка (перенос)
- `\t` — табуляция
- `\"` — вставить двойную кавычку внутрь строки (например: `"Он сказал: \"Привет!\""`)
