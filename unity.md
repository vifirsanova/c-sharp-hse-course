# Задание: «Hello, Unity!»

## Инструкция

**1. Создайте скрипт.**
В панели Project: правый клик → Create → Scripting → MonoBehaviour Script. Назовите `HelloWorld`.

**2. Добавьте логирование.**
Дважды кликните по файлу — он автоматически откроется в VS Code. Добавьте в метод `Start()` строку:

```csharp
Debug.Log("Hello, Unity!");
```

Сохраните файл.

**3. Прикрепите скрипт к объекту.**
Перетащите файл скрипта из Project на объект в Hierarchy (либо выберите объект → Add Component → введите `HelloWorld`). Убедитесь, что в Inspector появился компонент **Hello World (Script)**.

**4. Запустите сцену.**
Нажмите **Play**. Откройте **Console** (Ctrl+Shift+C). В консоли должно появиться `Hello, Unity!`.

**5. Сделайте скриншот.**
На скриншоте должны быть одновременно видны сцена и консоль с сообщением `Hello, Unity!`. Отправьте скриншот преподавателю.
