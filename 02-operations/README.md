### Базовые операции
| Оператор | Действие | Пример (`int a = 10, b = 3`) | Результат |
| :--- | :--- | :--- | :--- |
| `+` | Сложение | `a + b` | `13` |
| `-` | Вычитание | `a - b` | `7` |
| `*` | Умножение | `a * b` | `30` |
| `/` | Деление | `a / b` | `3` (целочисленное!) |
| `%` | Остаток | `a % b` | `1` |

---

Результат зависит от **типа данных** операндов:

1. **Целочисленное деление** (`int / int`) $\rightarrow$ результат всегда `int` (дробная часть просто отбрасывается).
   - `5 / 2` $\rightarrow$ `2`
2. **Дробное деление** (если хотя бы одно число `double` или `float`) $\rightarrow$ результат `double`.
   - `5.0 / 2` $\rightarrow$ `2.5`
   - `5 / 2.0` $\rightarrow$ `2.5`
   - `(double)5 / 2` $\rightarrow$ `2.5`

---

### Сокращённая запись (Комбинированные операторы)
Используются, когда нужно изменить значение переменной и сохранить его в неё же.

| Полная запись | Сокращение | Описание |
| :--- | :--- | :--- |
| `x = x + 5` | `x += 5` | Прибавить 5 к `x` |
| `x = x - 2` | `x -= 2` | Вычесть 2 из `x` |
| `x = x * 3` | `x *= 3` | Умножить `x` на 3 |
| `x = x / 4` | `x /= 4` | Разделить `x` на 4 |
| `x = x % 2` | `x %= 2` | Взять остаток от деления `x` на 2 |

---

### Инкремент и декремент (Шаг $\pm 1$)
| Оператор | Действие | Пример | Результат |
| :--- | :--- | :--- | :--- |
| `++` | Увеличить на 1 | `x++` или `++x` | `x = x + 1` |
| `--` | Уменьшить на 1 | `x--` или `--x` | `x = x - 1` |

---

### Порядок вычислений
1. Действия в скобках `( )`
2. Умножение `*`, деление `/`, остаток `%` (слева направо)
3. Сложение `+`, вычитание `-` (слева направо)
