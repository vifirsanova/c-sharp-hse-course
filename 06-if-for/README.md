# Инструкция: как сдавать задачи

## 1. Создайте скрипт в Unity

В панели **Project** правый клик → **Create → Scripting → MonoBehaviour Script**. Назовите скрипт так, как указано в задаче. Unity положит его в папку `Assets/`.

## 2. Напишите код

Откройте скрипт двойным кликом, он откроется в VS Code. Напишите решение задачи, сохраните файл.

## 3. Проверьте в Unity

Перетащите скрипт на объект в **Hierarchy**. Нажмите **Play**. Убедитесь, что в **Console** появляется нужный вывод.

## 4. Сдайте через Git

Откройте терминал в корне проекта и выполните три команды:

```bash
git add Assets/ИмяСкрипта.cs
git commit -m "taskN done"
git push
```

Например, для первой задачи:

```bash
git add Assets/PressCounter.cs
git commit -m "task1 done"
git push
```

## 5. Пришлите ссылку

Отправьте в Telegram ссылку на свой репозиторий.

## Требования

Один коммит — одна задача. Сообщение коммита: `task1 done`, `task2 done` и так далее.
